# ZLUIAtlas

**zhaoli-free-ui-atlas** — 由 zhaoli 维护的免费开源 UI 组件图鉴。

在网页中浏览和体验组件，复制接入提示词、下载独立源码，也可以通过 Agent Skill 搜索和使用组件。

## 当前阶段

第一版正在建设：纯静态网站、组件预览、文档、搜索、提示词与下载。网站结构参考 [LeiBox](https://leibox.pantoria.cn/)，独立编写实现；不再分发来源许可不明确或禁止再分发的组件代码及素材。

后续会在完整目录分析后设计多维标签与组合筛选。X / 小红书链接待维护者配置。

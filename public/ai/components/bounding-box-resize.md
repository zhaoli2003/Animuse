# Bounding Box Resize / 选框拖拽缩放

Eight square handles morph into directional arrows, with live size pills, editable dimensions, and guides as the selection resizes.

八个方形控制点连续变成方向箭头，拖动时显示实时尺寸胶囊和辅助线，支持直接输入宽高。

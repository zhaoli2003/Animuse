# 多维筛选交付记录

2026-11-08。组件目录 `/components` 已接入多维筛选，保持静态网站，无数据库或业务后端。

## 已实现

- 全部 53 项组件使用统一分类记录：10 个主用途、组内具体类型、38 个视觉选项、16 个交互/输入与播放能力选项、框架和 12 个应用场景。
- 中英文组件名、关键词、用途及视觉词搜索；多个搜索词共同匹配。
- 同维度多选取并集，不同维度取交集。选父类包含全部子类，点击具体子类可从父类下钻；网址中冗余的父子选择会归一化，组件数量不重复计算。
- 选项数量按当前搜索与其他维度计算。零结果且未选中的选项禁用；已选条件始终可取消。
- 已选标签、移除单项、清除全部、空结果和放宽条件建议。
- 筛选条件保存在网址中，支持直接打开、分享、刷新、浏览器前进与后退。
- 全部组件详情有真实筛选链接。框架、TypeScript、技术依赖和作者信息保留说明用途。
- 手机默认折叠筛选区，搜索、结果数及已选条件保持可见；平板与桌面直接显示常用条件。深色、中英文、键盘操作均沿用现有机制。

示例：

- `/components?category=text-selection`：两个文字选区组件。
- `/components?visual=glass&framework=react`：同时满足玻璃风格与 React 框架的组件。
- `/components?category=text,input`：文字类与输入类的并集。

## 数据与维护

`src/data/atlas-taxonomy.ts` 统一生成网站目录和详情标签的筛选信息；`src/lib/atlas-filters.ts` 负责规则、网址解析与计数。已有的 `AI_DISCOVERY` 仍是用途、视觉、交互和搜索资料的基础；受控词表与场景归类在 taxonomy 中维护。

43 个本站源码包组件标记六框架，404 模板标记 Next.js，另九项当前框架字段保留“未标注”。“未标注”不表示不支持。技术与交互能力按已有声明维护，不从组件名称推断。

本轮提供的是网页多维筛选。既有 Skill CLI 和对外源码包目录仍提供原有 43 项，没有把九个外部来源条目伪装成可下载源码包。

## 兼容修复

- 详情返回动画只处理纯返回链接，带筛选参数的标签保持完整网址。
- 目录内部的筛选历史后退，不触发旧详情卡片的返回动画或滚动恢复。
- 清除搜索标签时，输入框同步清空，不因焦点恢复填回旧词。
- 本地静态服务按真实导出文件建立 Next 分段预取别名，支持扁平预取地址和实际嵌套文件路径。缺失或歧义地址保持 404，预取不回退到 HTML。
